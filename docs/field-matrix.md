# Матрица новой структуры Google Sheets

| Столбец Google Sheets | Источник в Битрикс24 | Статус / действие |
|---|---|---|
| Номер | «Номер заказа» | Поле уже есть. Если оно пустое, используется ID сделки |
| Дата принт | «Срок выполнения заказа» | Поле уже есть. Строка `ДД.ММ.ГГГГ`; принято предположение, что срок выполнения равен дате печати |
| Клиент | Связанный контакт или компания | Дополнительное поле сделки не требуется |
| Как оплачивал | «Оплата» | Поле уже есть, значение списка преобразуется в его название |
| Сумма заказа | `opportunity` | Стандартная сумма сделки |
| ТЗ ( материал, технология, квадратура) | Составляется из «Материал заказа», «Технология», «Площадь работы, м2» и «ТЗ заказа в производство» | «Площадь» и производственное ТЗ уже есть. Нужно добавить «Материал заказа» и «Технология» |
| Макет/ закупка/ доставка х1.5 | Одноименное пользовательское поле | **Добавить** числовое поле. Интеграция не угадывает финансовую формулу |
| У кого | `assignedById` | Принято предположение, что это ответственный за сделку. Если речь о подрядчике/производстве, нужно отдельное поле «У кого» |
| Сумма факт | «Себестоимость производства» | Поле уже есть |
| Дельта | Формула Google Sheets | Скрипт не изменяет столбец |
| комментарий если надо | Ручное значение Google Sheets | Скрипт не изменяет столбец |
| Bitrix24 Deal ID | ID сделки | Служебный столбец `L`, создаётся автоматически |
| Ссылка на сделку в Битрикс24 | URL карточки сделки | Видимый столбец `M`, создаётся автоматически |
| Дата создания сделки в Б24 | `createdTime` | Стандартное поле сделки; строка `ДД.ММ.ГГГГ`; видимый столбец `N`, создаётся автоматически |
| Дата перехода сделки в Успешно реализовано | Первая запись стадии `WON` из `crm.stagehistory.list` | Строка `ДД.ММ.ГГГГ`; видимый столбец `O`, создаётся автоматически |
| Тип сделки | Пользовательское поле `UF_CRM_1790575342` (`ufCrm1790575342`) | Значение списка преобразуется в название; видимый столбец `P`, создаётся автоматически |
| Дата выставлен счет | Первая запись стадии `PREPAYMENT_INVOICE` из `crm.stagehistory.list` | Строка `ДД.ММ.ГГГГ`; видимый столбец `Q`, создаётся автоматически |

## Поля, которые нужно добавить

Минимальный набор при сохранении принятых предположений:

1. «Материал заказа» — строка или список.
2. «Технология» — строка или список.
3. «Макет/ закупка/ доставка х1.5» — число или деньги.

Если «Дата принт» отличается от срока выполнения заказа, добавьте отдельное поле «Дата принт» типа дата и измените правило в `config/mapping.php`.

Если «У кого» означает не ответственного сотрудника, добавьте поле «У кого» типа строка, список или привязка к сотруднику — в зависимости от процесса.

Для «Дельты» рекомендуется одна формула на весь столбец в Google Sheets. Базовый вариант: сумма заказа минус сумма фактических затрат. Нужно отдельно подтвердить, должен ли показатель «Макет/ закупка/ доставка х1.5» также вычитаться из дельты.
